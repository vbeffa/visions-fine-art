Scope
-----
- 3 complete design directions
- 20 representative artists in each design
- 622 real artwork-detail pages in each design
- 20 artist biographies in each design
- 8 gallery-information pages in each design
- shared local image assets from the repaired crawl

Prototype 3
-----------
The Virtual Tour homepage uses the exact Google 360 embed supplied during the design work.
A single screen-position hotspot demonstrates the proposed "interactive artwork" idea.
Hover (or click/tap) the large painting on the left side of the opening panorama to see
"Painting details here." The hotspot is deliberately aligned only to the initial view;
a production implementation would use panorama-aware coordinates/overlays.
